# Asset Generation Prompt

## 1. Asset ID
`hero-bg-lab`

## 2. Intended file path
`public/assets/hero/hero-lab-bg.webp`

## 3. Purpose
ヒーロー右側の背景になる、明るいAI研究室シーン。

## 4. Positive prompt in Japanese
青白ベースの明るく清潔なAI研究室の背景。白い棚、透明なガラス器具、淡い青の液体、観葉植物、柔らかい自然光、右奥に水色のホログラムUIパネル、手前に白い研究机。かわいいAIラボ感があり、未来的だが親しみやすい。左側はHTMLテキストを重ねられるように白くフェードし、右側に情報量を集める。

## 5. Negative prompt
日本語文字、英語文章、読めるUIテキスト、人物、猫、ロボット、暗い研究室、ホラー、汚れ、強い紫、過度なサイバーパンク、写真風すぎる質感、ロゴ、透かし。

## 6. Style constraints
ソフトブルーと白、少し温かいベージュを含む。クリーンで明るい、少し3Dイラスト風。丸みのあるかわいいAI研究所。

## 7. Composition
横長。左40%は白く淡く、右60%に棚、ホログラム、実験器具。キャラクターを後から重ねられる余白を中央右に残す。

## 8. Background requirement
背景込みの完成シーン。ページ背景になじむ白いフェードあり。

## 9. Transparency requirement
no

## 10. Recommended aspect ratio / size
16:9, `1600x900`

## 11. Consistency notes
soft blue and white palette; cute AI laboratory mood; fluffy ginger cat scientist and small cat-like robot companion will be layered separately; rounded friendly web design; clean, bright, slightly 3D illustration style.
