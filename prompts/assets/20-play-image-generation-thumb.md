# Asset Generation Prompt

## 1. Asset ID
`play-image-generation-thumb`

## 2. Intended file path
`public/assets/play/play-image-generation.webp`

## 3. Purpose
「画像生成であそぶ」カードの画像リッチなサムネイル。

## 4. Positive prompt in Japanese
白い丸角カード内に収まるミニイラスト。ふわふわのジンジャー猫博士がイーゼル横に立ち、キャンバスにカラフルなAI生成風の絵が表示されている。周囲に淡い青の小さな画像アイコンやキラキラ。明るくかわいいAIラボの作業風景。

読める日本語、カードタイトル、長い文字、暗い背景、怖い猫、写実的すぎる人物、雑な絵、透かし。

白・淡青・ネイビー、暖かい猫色。少し3Dイラスト調で、カード用に情報量を抑える。

## 7. Composition
横長カードサムネイル。左に猫博士、右にイーゼル/キャンバス。上下に余白。

## 8. Background requirement
淡い白〜薄青のカード内背景。

## 9. Transparency requirement
no

## 10. Recommended aspect ratio / size
26:21, `520x420`

## 11. Consistency notes
soft blue and white palette; cute AI laboratory mood; fluffy ginger cat scientist; small cat-like robot companion may be absent; rounded friendly web design; clean, bright, slightly 3D illustration style.
