# Asset Generation Prompt

## 1. Asset ID
`cta-social-icons`

## 2. Intended file path
`public/assets/social/*.svg`

## 3. Purpose
CTA下部の小さな丸型SNS風アイコンセット。

## 4. Positive prompt in Japanese
小さな丸いソーシャル風アイコン4点セット。白い円形または淡い背景に、X風の交差線、動画再生三角、音符、カメラ風マーク。実在ブランドを厳密に再現せず、汎用的でかわいい。

## 5. Negative prompt
実在ロゴの完全コピー、文字、ブランド名、複雑な色、写真風、透かし。

## 6. Style constraints
36pxで見える単純なSVG。白、ネイビー、赤/緑/ピンクの控えめアクセント。

## 7. Composition
各アイコンは正方形中央。セットで統一サイズ。

## 8. Background requirement
背景なしまたは円形白背景込み。

## 9. Transparency requirement
yes

## 10. Recommended aspect ratio / size
1:1, `36x36` each

## 11. Consistency notes
soft blue and white palette; cute AI laboratory mood; rounded friendly web design; clean icon style.
