## 0. これは何か（一言）

**ラボ案内ページを「暗い館内の机に置かれた、小さな案内冊子」として作り直す。**
現在の `/about` は「紙風の装飾を貼ったランディングページ」になっており、これを廃止して冊子に置き換える。

---

## 1. コンセプト：二層構造

画面には2つの世界だけが存在する。

| 層 | 世界 | ルール |
|---|---|---|
| 紙の**外** | 暗い館内（ラボの机の上） | サイト共通のダーク世界。`lab-ambient-bg.webp` を暗く敷く。装飾なし |
| 紙の**中** | 印刷された冊子 | 「印刷物の文法」だけで組む（下記2章） |

この境界を混ぜないこと。**ダークな帯セクションを紙の中に作らない**（現行の「はじまりの頃」「CTA帯」のような構成は廃止）。

---

## 2. デザインルール（違反したら差し戻し）

### 2.1 使ってよいもの
- 色は「2色刷り + 紙」のみ：
  - 紙 `#f9f2df` / インク紺 `#2a3550` / 特色teal `#0d685f`（CSS変数は試作 `--bk-*` を流用）
- 細い罫線（実線・点線・破線、1px、インク色を透過させたもの）
- タイポグラフィと余白
- 影は**冊子（紙）そのものに1つだけ**。紙の中の要素には影禁止
- フルカラーは「貼り込まれた図版」（地図・キャラ絵・写真）のみ。図版は白フチ+細罫で囲み、キャプション（例「図1｜よこぼのAIラボ 見取り図」）を付ける

### 2.2 禁止（現行CSSからの持ち込み禁止リスト）
- グラデーション、ノイズテクスチャ、方眼、光点、グロー、`mix-blend-mode`
- カードUI（角丸ボックス+ドロップシャドウ）。紙の中の角丸は原則0
- コーナー飾り（現行 `guide-card::before/::after`）
- hoverで浮く演出（`translateY` など）。hoverはインク色変化程度まで
- `font-weight: 800/900` の全面使用。本文は **500**、見出し・強調のみ 700（タイトルのみ900可）

### 2.3 フォント
- 冊子内は **Zen Maru Gothic**（500 / 700 / 900）
- 試作は `<link>` タグ読み込みだが、本実装では **`next/font/google`** に置き換えること（`display: "swap"`）
- 字間は試作準拠（見出しに `letter-spacing`、本文はゆったり `line-height: 2` 前後）

### 2.4 遊び要素の上限
- 印刷物ディテールの遊びは**スタンプ1個まで**（試作の「来館記念にゃ」を継続。位置・濃度も試作のまま）
- それ以外の飾りを足したくなったら足さない。**引き算がこのデザインの本体**

## 3. ページ構成：3枚の紙 + 紙の外のCTA

現行 `/about` の全コンテンツを、**3枚の紙（sheet）が縦に並ぶ構成**に再配置する。紙1枚ごとに試作の `booklet-proto__sheet` と同じ作り（枠罫二重・影1つ・ノンブル）とする。文言は原則、現行 `AboutLabPage.tsx` のデータ（`rooms` / `story` / `principles` / `topics`）をそのまま流用する。

### p.1（試作そのまま）
1. 天ヘッダー：「よこぼのAIラボ 館内案内」／「ご自由にお持ちください」
2. 表紙：LAB GUIDE BOOKLET ／ H1「よこぼのAIラボ ってなに？」／「館内のご案内」／スタンプ
3. **1 ごあいさつ**（リード文+「遊ぶ ⇄ 記録する」注記）
4. **2 館内マップ**（見取り図の貼り込み図版 + ROOM 1/2 の凡例）
5. 「— 次のページへつづく —」＋ 奥付行「発行｜よこぼのAIラボ」＋ p.1

### p.2
1. **3 このラボが生まれたきっかけ** — 現行のダーク帯を廃止し、**冊子に印刷された対談記事**として組む
   - 小さな丸アイコン（`drYokobo` / `nyabit`、細罫の丸フチ）+ 話者名（特色teal・小さく）+ セリフ（本文組み）
   - 吹き出しボックスは使わない。話者ごとに行を分け、点線罫で区切る程度
   - 締めの「AIに出会って、できることが一気に広がった。〜」は**引用ブロック**（左に特色tealの縦罫、少し大きめの文字）として置く
2. **4 ラボのきまり** — 現行「大切にしていること」4項目。カードグリッドをやめ、**番号付きの規約リスト**として組む
   - 番号（特色teal）+ 見出し（700）+ 本文（500）を1行組みし、項目間は点線罫
3. ノンブル p.2

### p.3
1. **5 ラボで扱っていること** — 現行6テーマ。**2列の目録**として組む
   - 各項目：小さめの図版（白フチ、60〜76px角）+ テーマ名（700）+ 説明（500）
   - hoverで浮かせない
2. **奥付（コロフォン）** — 冊子の締め。中央寄せの小さな文字ブロック：
   - 「よこぼのAIラボ 館内案内」／「発行：よこぼのAIラボ」／「案内係：Dr.よこぼ ＆ ニャビット」程度（文言はこの通りでなくてよいが3行以内）
3. ノンブル p.3

### 紙の外（巻末CTA）
- p.3 の下、**暗い館内側**に置く（冊子を読み終えて顔を上げたら部屋の入口がある、という位置づけ）
- 導入の一言（例「それでは、ラボの中へ。」白系の小さめ文字）+ 既存 `LabButton` ×2（実験室へ / 資料室へ）。`AboutLabPage.tsx` の `about-closing__actions` と同じ props を流用
- キャラ画像・グロー・背景写真の帯は置かない。暗い床にボタン2つと一言だけ
- 既存 `Footer` コンポーネントはその下に従来通り配置（フッター自体の改造は不要。現行 `about-page.css` のフッター上書きは廃止し素のフッターでよい）

## 4. 実装方針

| 項目 | 内容 |
|---|---|
| コンポーネント | `AboutBookletProto.tsx` を `AboutLabPage.tsx` の置き換えとして拡張（名前は `AboutLabPage` に戻してよい）。試作の class 名 `booklet-proto__*` は `about-booklet__*` 等に整理してよい |
| CSS | `about-booklet-proto.css` をベースに全章分へ拡張し、**旧 `about-page.css` は削除**（`app/layout.tsx` の import も差し替え）。CSS冒頭のデザインルールコメントは残すこと |
| ルート | `/about` を新実装に切り替え。**確認後、試作ルート `app/about-proto/` は削除** |
| ヘッダー | 現行どおり `<Header variant="dark" showNav />` |
| フォント | `next/font/google` の Zen Maru Gothic に置き換え（2.3参照） |
| アクセシビリティ | 試作準拠：見出しに `aria-labelledby`、図版に意味のある `alt`、装飾画像は `alt=""` + `aria-hidden` |
| データ | 文言・画像パスは現行 `AboutLabPage.tsx` の配列から流用。新規画像の生成・追加は不要 |

## 5. レスポンシブ

- ブレークポイントは試作準拠（640px）。紙は `width: min(760px, 100%)`、モバイルでは `padding` を絞り二重罫の内側1本を消す（試作実装済み）
- モバイルの凡例・目録は1列に落とす
- 375px幅で横スクロールが出ないこと

## 6. 検証（完了条件）

1. `npm run lint` / `npm run typecheck` / `npm run build` が通る
2. デスクトップ（1280px）と モバイル（375px）で `/about` を目視確認、コンソールエラーなし
3. 2章の禁止リストに該当するCSSが残っていないこと（特に旧 `about-page.css` の残骸）
4. 変更点と残課題を報告

## 7. やらないこと（非ゴール）

- ページめくりアニメーション、紙めくり音などの演出
- 紙テクスチャ画像・ノイズの追加（フラットな紙色で成立させる）
- 新規イラスト・アイコンの生成
- 他ページ（`/` `/experiments` `/read` など）への波及変更
- ヘッダー・フッター自体の改造
